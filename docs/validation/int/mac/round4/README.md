Four Mac table rows from before the 1.0.0 freeze, kept only because the model catalog
(`poros/catalog.toml`) and a test cite them: `receipts/<row>/` for Qwen2.5-7B (256 tokens),

their packs' sizes. No figure in the README, the docs or the paper comes from them.
